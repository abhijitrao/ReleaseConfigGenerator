AppStore - Config Manager

Usage guide for Windows and Linux desktop builds.

Windows

  1. Download AppStore - Config Manager.exe and keep it in a folder of your choice.
  2. Install Google Chrome.
  3. Double-click the EXE to start the application.
  4. To use the buttons above, open this Usage Guide from the running application's local page.

Linux

  1. Download AppStore - Config Manager and keep it in a folder of your choice.
  2. Install Google Chrome or Chromium.
  3. Make the file executable with chmod +x "AppStore - Config Manager".
  4. Run it with ./"AppStore - Config Manager" (or launch it from your file manager).
  5. To use the buttons above, open this Usage Guide from the running application's local page.

Requirements and notes

  • Python is not required on the target machine.
  • Google Chrome or Chromium must be installed.
  • The app uses a local-only server at 127.0.0.1:8766.
  • Windows EXE and Linux executable are separate builds; do not use one on the other operating system.

The Launch Application button starts the executable located beside the packaged launcher. If the application is already running, its single-instance protection may show an “already running” message instead of opening a second copy.
