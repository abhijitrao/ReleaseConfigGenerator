How to run

  1. Click Download for Ubuntu.
  2. Open your Downloads folder and extract AppStore-Config-Manager-Ubuntu.tar.gz.
  3. Open the extracted AppStore-Config-Manager folder.
  4. Right-click AppStore - Config Manager and open Properties → Permissions.
  5. Enable Allow executing file as a program, if it is not already enabled.
  6. Close Properties and double-click the executable. Choose Run if Ubuntu asks how to open it.

Requirements

  • Ubuntu 64-bit desktop.
  • Google Chrome or Chromium must be installed.
  • Python is not required on the target computer.

Note: Download the package only from your trusted release source. If Ubuntu displays a security prompt, verify the source before allowing the application to run.
