Select your operating system to download and use the application. Keep this usage.html file in the same parent directory as the Windows and Linux folders.

Windows

For Windows 10 / 11. Download the EXE and run it from your computer.

Windows/AppStore - Config Manager.exe
  1. Click Download and save the EXE.
  2. Install Google Chrome if it is not already installed.
  3. Open the downloaded EXE to launch the application.

Linux

For supported Linux desktop distributions. Download the Linux executable.

Linux/AppStore - Config Manager
  1. Click Download and save the file.
  2. Install Google Chrome or Chromium if it is not already installed.
  3. Allow execution, then launch the file.
Download for Linux Run / Open

chmod +x "AppStore - Config Manager"

Important information

  • Google Chrome or Chromium must be installed on the target computer.
  • Python is not required on the target computer.
  • Windows and Linux use different executable files. Download the one matching your operating system.
  • After downloading on Linux, run chmod +x "AppStore - Config Manager" in the downloaded file's directory if needed.

About Run / Open: A normal HTML page cannot directly execute an EXE or Linux binary because browsers block websites from launching local programs. This link asks the browser to open or download the selected file; depending on the browser and operating system, you may need to open the downloaded file manually. The Download buttons save the corresponding executable using your browser's normal download location or save dialog.
