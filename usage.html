AppStore - Config Manager

Choose your operating system, download the application, and open it from your Downloads folder.

🪟

Windows

For Windows 10 / 11.

AppStore - Config Manager.exe
  1. Click Download for Windows.
  2. Open your Downloads folder.
  3. Double-click AppStore - Config Manager.exe to start the application.
Download for Windows
🐧

Linux

For supported Linux desktop distributions.

AppStore - Config Manager
  1. Click Download for Linux.
  2. Open your Downloads folder.
  3. If needed, allow the file to run in its Properties / Permissions, then double-click it.
Download for Linux

Before you start

  • Download the build matching your operating system.
  • Extract the downloaded package first if it is provided as a ZIP file.
  • Google Chrome or Chromium must be installed. Python is not required on the target computer.

Note: If Windows shows a security warning, verify that the EXE came from your trusted release source before choosing to run it.
