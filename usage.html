Windows

For Windows 10 / 11.

Windows/AppStore - Config Manager.exe
  1. Download the Windows executable.
  2. Open your Downloads folder.
  3. Double-click AppStore - Config Manager.exe to start the application.

Linux (Ubuntu)

For Ubuntu desktop (64-bit).

Linux/AppStore - Config Manager
  1. Download the Linux executable.
  2. Open your Downloads folder.
  3. If needed, right-click AppStore - Config Manager, open Properties → Permissions, and enable Allow executing file as a program.
  4. Double-click AppStore - Config Manager and choose Run if prompted.
Download for Linux (Ubuntu)

Requirements

  • Google Chrome or Chromium must be installed.
  • Python is not required on the target computer.
  • Download the executable matching your operating system.

Note: If your browser or operating system displays a security warning, verify that the file came from your trusted release source before choosing to run it.
