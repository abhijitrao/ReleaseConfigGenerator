Windows

For Windows 10 / 11. Download the EXE or register the Run button once for the current Windows user.

Windows/AppStore - Config Manager.exe
  1. Click Download to save the EXE.
  2. Keep the EXE in the Windows folder shown above.
  3. Right-click install-run-handler-windows.ps1 and choose Run with PowerShell. If script execution is blocked, open PowerShell in this folder and run:
    powershell -ExecutionPolicy Bypass -File .\install-run-handler-windows.ps1
  4. Return to this page and click Run. Confirm the browser's external-app prompt.

Linux

For supported Linux desktop distributions. Download the Linux executable or register the Run button once.

Linux/AppStore - Config Manager
  1. Click Download to save the Linux executable.
  2. Keep the executable in the Linux folder shown above.
  3. Open a terminal in this parent folder and run:
    bash install-run-handler-linux.sh
  4. Return to this page and click Run. Confirm the browser's external-app prompt.

How Run works

  • The setup script registers the appstore-config:// protocol for the current OS user. It does not require administrator/root privileges.
  • When Run is clicked, the browser asks for confirmation to open the registered AppStore Config Manager application. Accept that prompt to launch it.
  • Download always downloads the executable using the browser's normal download settings.
  • Google Chrome or Chromium must be installed. Python is not required on the target computer.
  • Windows and Linux require their matching executable and matching registration script.

Security: Browsers intentionally require user confirmation before opening an external application. This is the closest supported equivalent to an Android runtime permission prompt. The page cannot silently grant execution permission or bypass Windows/Linux security controls.
